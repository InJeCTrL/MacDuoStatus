## Duo Status

macOS 菜单栏 Wi-Fi 与电池二合一工具。

- 电量环、Wi-Fi 信号、横向插头供电状态，自动适配深浅色菜单栏。
- 电池 / Wi-Fi 分区面板，显示充满时间、供电来源和当前网络。
- 支持 Wi-Fi 开关与可选电量百分比。
- 首次启动请求定位权限，仅用于读取 Wi-Fi 网络名，不收集地理位置。

### 下载与安装

下载 `MacDuoStatus-universal.zip`，解压后将 `Duo Status.app` 拖入「应用程序」。
支持 macOS 13+，同一 App 包含 Apple Silicon 和 Intel 架构。
`SHA256SUMS.txt` 用于验证下载文件完整性。

### 签名说明

本版本只有 ad-hoc 临时签名，尚未使用 Apple Developer ID 签名或公证。
macOS 可能阻止首次启动；确认下载来源后，可在「系统设置 → 隐私与安全性」中选择「仍要打开」。
无需全局关闭 Gatekeeper 或 SIP。

### 已知限制

- Wi-Fi 格数复现已核对的系统换算公式，不保证跨系统版本逐帧同步。
- 网络名受系统定位权限控制；拒绝后需在系统设置中授权。
- 后台采用事件驱动与低频兜底轮询，仅在图标状态变化时重绘。
